# v22 – Tap to start + intro music, one credit line, update button (local, not published)
- Credit: the title footer reads "v22 · A Slimetrail production" (Jeremy: "Use: A Slimetrail production"). CREDITS.md uses the same single line. Third-party licence notices are unchanged.
- Tap to start (like Shark Attack): every launch (cold open, reload, back/forward restore outside a run) shows a dark full-screen "Tap to start". The tap (or a key) unlocks sound and starts the ~9.5 s intro movie from 0 together with the existing intro music `sounds/intro-elise-dino-variation.ogg` (own work, CC0, licence in licences/). No audio file added or changed.
- The music plays once per launch on the existing music bus (same gain, music slider and sound on/off apply). Skipping the intro does not restart or stop it; it keeps playing into the title and stops when a run starts, as before. A restore stops any earlier copy before the new one, so copies never overlap. The intro music bytes are fetched at page load so they are ready at the tap.
- Update button: the page re-checks for a new version on open/focus and every 5 minutes. The new worker caches every file, then takes over; only then a small "Update ready — tap to reload" button shows bottom-left (never on the first install, held back while a run is going, never reloads by itself).
- Hard mode (Jeremy's correction, Dino only): fewer spear people (Hard multiplier 0.35, sections 1-10 go from 102 to 46 spear people in total; Easy and Medium unchanged). The silly human (Hard only) now runs to the dino and is always eaten automatically ("GULP! Silly human!") during its 1.2 s warning, so it can never be missed; it has no hitbox and cannot hurt.
- `?intro=0` still means no tap screen and no intro.
- Version 22: sw VER and SHELL ?v=, index.html ?v=, footer. tests/test_v22.py added; test_v21 taps the start screen first; older credit checks use the new wording.
