# Dino Colossus credits

A Slimetrail production

## Music (v19, loops updated v20)
In game: "A Slimetrail production" (one credit line only, v22).

- `sounds/intro-elise-dino-variation.ogg` (title intro, plays once): our arrangement of the public-domain Für Elise motif.
- `sounds/dino-main-loop.ogg` (main play music, whole file loops).
- `sounds/dino-boss-loop.ogg` (boss music, whole file loops).
- `sounds/boss-beaten-fanfare.ogg` (plays once when a boss is beaten).

All four are original work released CC0, made with the CC0 VSCO-2 CE upright piano samples.
Licence texts are saved in `licences/` (OWN-WORK-CC0.txt, VSCO-2-CE-upright-CC0-1.0.txt). No credit is required.

## Sound effects (v13)
stomp, land, chime, cheer, sparkle (`sounds/*.mp3`) were added in v13 as CC0 effects from Kenney (kenney.nl), and `sounds/roar.mp3` as the "Retro Monster Roar" (OpenGameArt). Status: UNVERIFIED, see `licences/SOUND-EFFECTS-UNVERIFIED.txt`.
- Correction (v25): the "Retro Monster Roar" page names **greg300** as the author, with licence CC0 (https://opengameart.org/content/retro-monster-roar, read 2026-11-01). "SdiviHall" is only a commenter on that page, so the old "SdiviHall" credit was wrong.
- Which Kenney pack each effect came from was never recorded, so the Kenney licence cannot be checked file by file.
